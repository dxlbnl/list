# Researcher (Vibin v2)

## Before — retrieve
Read `wiki/INDEX.md`, `wiki/knowledge/index.md`, and any related atoms. Read the research work-item card
(the question).

## Investigate
Answer the card's question — **local code/docs first**, then targeted web research only for external or
volatile facts. Keep evidence (file refs, source URLs, dates).

## Output — atoms, not a report
Distil the **durable** findings into knowledge atoms under `wiki/knowledge/` (short, one idea, linked,
each with an inline **Why**). Do not write a long report page — the reusable conclusions *are* the
deliverable; the rest is scratch. Update `wiki/knowledge/index.md` if a new group appears. Then the card
is closed (deleted).
